# MeloFi

Windows용 가상 피아노이자 작곡 스튜디오입니다. 키보드로 바로 연주하고, 악보를 불러와 듣고, 곡을 처음부터 만들거나 완성된 음원을 악기별로 나눠 MIDI로 옮길 수 있습니다. 음원 분석까지 모든 처리가 이 PC 안에서 이루어집니다.

[English](README.en.md)

## 다운로드

[Releases](https://github.com/mikatz1/MeloFi/releases)에서 `MeloFi-Setup-<버전>.exe`를 받아 실행하세요. Windows 10·11 64비트용입니다.

- 아직 코드 서명이 없어 처음 실행할 때 SmartScreen 경고가 뜰 수 있습니다. **추가 정보 → 실행**을 누르면 됩니다.
- 새 버전이 나오면 앱이 알려 줍니다. 받기와 설치는 직접 눌러야 진행됩니다.

## 무엇을 할 수 있나요

### 피아노

- PC 키보드나 MIDI 건반으로 연주합니다. 댐퍼·소스테누토·소프트 페달을 지원합니다.
- MuseScore, MusicXML, MIDI 악보를 열면 오른손과 왼손을 나누고 반복, 셈여림, 페달까지 반영해 연주합니다.
- 연주를 4K 60fps 영상, MP3, WAV, MIDI로 내보냅니다. 영상은 프레임 단위로 렌더링해 음이 많은 곡도 밀리지 않습니다.
- 테마 12종과 배경, 오디오 스펙트럼, 방송용 화면 크기를 고를 수 있습니다.

### MeloFi Studio

FL Studio와 같은 방식으로 패턴을 만들어 플레이리스트에 쌓는 작곡 화면입니다. 메뉴와 상단 툴바 배치, 단축키가 FL Studio와 같습니다. 처음 열면 13강짜리 투어가 화면을 하나씩 안내합니다.

- **채널 랙과 피아노 롤**: 스텝 시퀀서, 스윙과 그루브, 아르페지에이터, 스케일 고정, 코드 도구, 슬라이드 노트, 퀀타이즈, Riff Machine
- **플레이리스트**: 패턴·오디오·오토메이션 클립, 마커, 템포 변화, 라이브 모드, 마이크 녹음
- **믹서와 마스터링**: EQ, 컴프레서, 리버브, 사이드체인 등 이펙트 체인, 트루 피크 리미터, LUFS 기준 자동 마스터링
- **신디사이저**: 파형 11종, FM, 드라이브를 갖춘 내장 신스와 프리셋 141개
- **보컬**: 멜로디에 가사를 붙이면 오픈소스 가창 합성기가 부릅니다. 남성 2명과 여성 2명의 보이스를 앱에서 받을 수 있고, 녹음된 노래에서 가사를 알아듣고 음절을 붙여 줍니다.
- **VST3 악기**: PC에 설치된 VST3 악기 플러그인을 채널로 불러옵니다.
- **연동**: MIDI 가져오기·내보내기, 스템과 REAPER 프로젝트로 보내기, MIDI 클럭 출력

### AI 음원 분리와 MIDI 변환

- 음원 파일을 보컬, 드럼, 베이스, 기타, 피아노 등으로 나누고 박자, 템포, 음표를 읽습니다. 오픈소스 모델이 이 PC에서 돌아가고, 음원을 외부 서버로 보내지 않습니다.
- 나눈 파트마다 음색을 MeloFi의 악기와 하나씩 비교해 가장 비슷한 악기를 일치율과 함께 추천합니다. 후보를 들어 보고 고를 수 있습니다.
- 분석 엔진은 버튼 하나로 설치됩니다. Python을 따로 설치할 필요가 없습니다.

### 악기

무료로 공개된 샘플 라이브러리에서 고른 악기 220여 종을 갖추고 있습니다. 피아노, 일렉트릭 피아노, 오르간, 신디사이저(Juno, JD-800, SH-2 샘플 포함), 현악과 관악 섹션, 기타와 베이스, 말렛, 드럼 키트, 코토와 샤미센 같은 세계 악기까지 들어 있습니다.

- 기본 피아노 외의 악기는 필요할 때 원작자의 배포처에서 바로 내려받습니다. 압축 파일이나 사운드폰트로만 배포되는 악기도 필요한 부분만 받아 이 PC에서 풉니다.
- 모든 샘플은 무손실이며, 음높이와 음량을 악기마다 측정해 맞춰 두었습니다.

### 그 밖에

- 한국어와 영어를 지원합니다.
- 마이크와 MIDI 건반의 입력 지연을 측정해 녹음 위치를 보정합니다.
- 예전 버전에서 저장한 프로젝트도 같은 소리로 열립니다.
- 오류 기록은 이 PC에만 남습니다. 문제 신고를 누르면 직접 확인한 내용만 파일이나 GitHub 이슈로 보낼 수 있습니다.

## 소스에서 실행하기

```bash
npm install
npm start
```

설치 파일은 `npm run dist`로 만듭니다. 악기 음원을 다시 만들려면 ffmpeg가 필요합니다.

```bash
node tools/build-instruments.mjs <악기 id>   # 원본 라이브러리에서 무손실 FLAC과 매핑 생성
node tools/check-pitch.mjs <악기 id>         # 음높이 검사
```

## 테스트

앱을 화면 없이 띄워 실제 기능을 끝까지 사용해 보는 E2E 테스트가 있습니다.

```bash
MELOFI_SHOT=out MELOFI_SCRIPT=tools/e2e/studio-e2e.js MELOFI_USERDATA=out/ud npx electron .
node tools/e2e/compat-run.mjs
node tools/test-repeats.mjs
```

스튜디오, 마스터링, 보컬, 입력 지연, 호환성, 언어 전환 테스트가 `tools/e2e/`에 있습니다. 결과와 비교 자료는 [`docs/`](docs)에 정리해 두었습니다.

## 라이선스와 출처

- 지금은 비상업 용도로만 배포합니다. 일부 악기와 보이스, 분석 모델이 비상업 라이선스를 따르기 때문입니다. 해당 항목은 앱에 따로 표시됩니다.
- 악기마다 원작자, 라이선스, 원본 주소를 앱의 악기 정보와 각 `instruments/<id>/manifest.json`에 적어 두었습니다. CC0, CC BY, CC BY-SA, CC Sampling Plus, MIT 등 공개 라이선스를 확인한 라이브러리만 사용했습니다.
- SFZ 매핑의 상당수는 [sfzinstruments](https://github.com/sfzinstruments)의 작업을 바탕으로 합니다.
- 테스트용 악보는 MuseScore 테스트 모음에서 가져왔습니다(GPL-3.0).
