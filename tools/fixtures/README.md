# Test fixtures

The `.mscx` / `.mxl` / `.xml` scores and the `.cpp` files here come from MuseScore's own test suite
(https://github.com/musescore/MuseScore, GPL-3.0). They are used only by `tools/test-*.mjs` to check that
MeloFi plays repeats, jumps, tempo changes and imports the same way MuseScore does.
