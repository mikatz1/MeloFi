# MeloFi Studio vs FL Studio — 1:1 비교

초보자에게 중요한 순서로 정리했습니다. 상태: ● 있음 · ◐ 일부 · ○ 없음.

## 1. 시작하기 · 배우기

| FL Studio | MeloFi Studio | 상태 | 비고 |
| --- | --- | --- | --- |
| 튜토리얼 영상 / 힌트 바 | 단계별 투어 3장 (첫 비트 → 코드·멜로디 → 곡·믹스), 하단 힌트 바 | ● | 투어는 직접 해 보면 자동으로 다음 단계로 넘어감 |
| 템플릿 프로젝트 | 빈 / 기본 비트 / 케이팝 / 트랩 / 로파이 / 발라드 / 시티팝 | ● | 템플릿마다 노트·이펙트·곡 구성 포함 |
| 브라우저 (샘플·프리셋) | 브라우저 패널 (내 폴더, 프로젝트 오디오, 악기) | ◐ | 프리셋 공유 라이브러리는 없음 |
| 가상 건반 / 타이핑 키보드 | 화면 건반 + PC 키보드 + MIDI 건반 | ● | |
| 최근 프로젝트, 자동 저장 | 최근 프로젝트, 15초 자동 저장, 5분마다 버전 기록 20개 | ● | |

## 2. 리듬 (채널 랙 · 스텝 시퀀서)

| FL Studio | MeloFi Studio | 상태 | 비고 |
| --- | --- | --- | --- |
| 스텝 시퀀서 | 칸 클릭·드래그 칠하기 | ● | |
| 그래프 에디터 (스텝별 세기·팬·피치) | 스텝 그래프 (세기 / 팬 / 피치) | ● | |
| Fill each 2/4/8 steps | 스텝 채우기 2·4·8칸, 무작위 리듬, 밀기·당기기 | ● | |
| 채널별 스윙 | 채널별 스윙 + 그루브 템플릿 5종 | ● | |
| 채널별 패턴 길이 | 스텝 반복 길이 (폴리리듬) | ● | |
| Channel arpeggiator | 채널 아르페지에이터 (재생할 때 화음을 펼침) + 피아노 롤 아르페지오 도구 | ● | |

## 3. 멜로디 · 화음 (피아노 롤)

| FL Studio | MeloFi Studio | 상태 | 비고 |
| --- | --- | --- | --- |
| 스케일 하이라이트 | 스케일 9종 표시 + 스케일 밖 음 막기 | ● | |
| Stamp (화음 찍기) | 코드 도구 (스케일 화음 자동, 3·7화음, 10종) | ● | |
| Arpeggiate / Strum / Randomize | 아르페지오, 스트럼, 휴머나이즈, 세기 무작위 | ● | |
| Quantize (강도·길이) | 퀀타이즈 (격자, 강도, 길이) | ● | |
| Legato, Flip, Reverse | 레가토, 위아래·좌우 뒤집기, 옥타브 겹치기 | ● | |
| Slide notes | 슬라이드 노트 (샘플러·신스 모두 글라이드) | ● | |
| Note properties (pan, fine pitch, mod X/Y) | 노트별 세기·팬·미세 피치 | ◐ | 모드 X/Y는 없음 |
| Ghost notes | 다른 채널 노트 흐리게 표시 | ● | |
| Score logger | 방금 연주한 것 패턴에 넣기 (최근 5분) | ● | |
| Riff Machine | 무작위 리듬 (스텝) | ◐ | 멜로디 자동 생성은 없음 |
| Chop / Glue | 노트 자르기 (스냅 길이), 노트 붙이기 | ● | |

## 4. 곡 구성 (플레이리스트)

| FL Studio | MeloFi Studio | 상태 | 비고 |
| --- | --- | --- | --- |
| 패턴 클립 배치·복제·늘이기 | 그리기, Ctrl+끌기 복제, 오른쪽 끝 늘이기 | ● | |
| Slice tool | 자르기 도구 (패턴·오디오·자동화 클립) | ● | |
| Make unique | 고유 패턴으로 만들기 | ● | |
| 오디오 클립 (스트레치, 페이드, 게인) | 오디오 클립: 템포 맞추기(피치 유지), 페이드, 게인 | ● | |
| 자동화 클립 | 자동화 클립 (점 찍기·끌기, 상승·하강 곡선) | ● | 모든 노브·페이더 우클릭으로 생성 |
| 트랙 이름·음소거·솔로 | 트랙 헤더 (이름, M, S, 추가·삭제) | ● | |
| 마커, 반복 구간 | 마커, 눈금자 드래그로 반복 구간 | ● | |
| 템포 자동화 | 마디 단위 템포 변화 | ◐ | 부드러운 템포 곡선은 없음 |
| 박자표 변화 | 곡 전체 박자 하나 | ○ | |
| Performance mode | 라이브 모드 (트랙×패턴 그리드, 다음 마디에 전환, 플레이리스트로 옮기기) | ● | |
| Split by channel | 채널별로 패턴 나누기 | ● | |

## 5. 소리 만들기

| FL Studio | MeloFi Studio | 상태 | 비고 |
| --- | --- | --- | --- |
| 기본 악기 (FL Keys, Sytrus, 3xOsc…) | 악기 65종 (다운로드 센터) + 편집 신스 + 프리셋 13개 | ● | |
| 3x Osc / Sytrus 편집 | 신스: 오실레이터 2 + 서브 + 노이즈, 유니즌, 필터·앰프 엔벨로프, LFO, 글라이드 | ◐ | FM·웨이브테이블은 없음 |
| Sampler (Audio Clip channel) | 샘플 채널: 시작·끝, 기준음, 반전, 루프, 어택·릴리스 | ● | |
| Slicex / Fruity Slicer | 슬라이서: 소리 시작점·같은 간격 자르기, 패턴 만들기 | ● | |
| Edison (녹음·편집) | 마이크 녹음 → 오디오 클립 (지연 보정), 노멀라이즈·거꾸로·앞뒤 무음 자르기 | ◐ | 파형 위 부분 선택 편집은 없음 |
| Newtone / Pitcher (피치 보정) | 없음 | ○ | |
| VST / VST3 플러그인 | VST3 악기 채널 (MeloFi VST Host: 스캔, 플러그인 창, 설정 저장, 오프라인 렌더) | ◐ | VST3 이펙트를 믹서 슬롯에 넣는 것은 아직 없음, VST2 미지원 |
| 보컬 합성 (FL 기본 없음, Vocaloid·Synthesizer V 연동) | 보컬 채널: 멜로디 + 가사(히라가나·가타카나) → NNSVS 가창 합성 → 오디오 트랙 | ◐ | 무료 보이스 1종(일본어), 엔진 설치에 Python과 C++ 빌드 도구 필요 |
| Stem separation / AI 분석 | AI로 곡 분석·재구성: 템포·조성·박 단위 코드·베이스·드럼·멜로디 분석, Claude가 리포트와 재구성 프로젝트 작성 | ◐ | 악기별 분리(스템)는 없음, Claude는 API 키 필요 |

## 6. 믹싱 · 마스터링

| FL Studio | MeloFi Studio | 상태 | 비고 |
| --- | --- | --- | --- |
| 믹서 트랙, 이펙트 슬롯 | 채널·버스·마스터마다 이펙트 체인 | ● | |
| 기본 이펙트 | EQ, 컴프레서, 필터, 디스토션, 코러스, 딜레이(템포 싱크·핑퐁), 리버브, 스테레오 폭, 사이드체인, 리미터 | ● | |
| 라우팅 / 버스 | 채널 → 버스 → 마스터 | ● | 센드 버스 여러 개는 없음 (리버브 센드 1개) |
| 사이드체인 | 노트 기반 사이드체인 (킥 등 채널 지정) | ● | |
| Wave Candy, Loudness | 마스터 LUFS (순간·3초·전체), 스펙트럼, 레벨 미터 | ● | |
| 이펙트 프리셋 | 이펙트 체인 프리셋 7종 (보컬 리버브, 킥 펀치, 로파이, 808 진하게, 마스터 기본…) | ● | |

## 7. 내보내기 · 연동

| FL Studio | MeloFi Studio | 상태 | 비고 |
| --- | --- | --- | --- |
| WAV / MP3 / OGG / FLAC | WAV 24·16비트, MP3 320kbps, 반복 구간만 | ◐ | OGG·FLAC 없음 |
| 스템 내보내기 | DAW로 보내기 (채널별 스템, 믹스, MIDI, REAPER 프로젝트) | ● | |
| MIDI 내보내기·가져오기 | ● | ● | |
| 영상 (ZGameEditor) | 떨어지는 노트 영상 (4K·60fps, 실제 믹스 소리) | ● | |
| Consolidate / Render to audio | 오디오로 굳히기 | ● | |
| MIDI 컨트롤러 연결 | MIDI 런 (우클릭 → 다음 노브), MIDI 클럭 출력 | ● | |
| 단축키 | 단축키 설정 | ● | |
| FL Cloud (샘플·공유) | MeloFi 계정 (온라인 저장, 공유 코드) | ◐ | 서버 배포 필요 |
