# FL Studio UI 항목별 재감사 (4차, 2026-11-14)

기준: Image-Line **FL Studio 온라인 매뉴얼**의 해당 페이지를 그대로 읽어 만든 체크리스트
(toolbar_panels, menu_file/edit/add/patterns/view/options/tools, channelrack, pianoroll, pianoroll_menu,
playlist, mixer, mixer_mixermenu, mixer_trackprops, browser, chansettings*, plugins/wrapper, basics_interface,
basics_shortcuts). 매뉴얼이 직접 말하지 않는 것(UNCONFIRMED)은 측정에서 뺐습니다.

점수: **●** 같은 위치·같은 조작 = 1 · **◐** 있으나 위치·범위·조작이 다름 = 0.5 · **○** 없음 = 0 ·
**—** FL 전용 서비스나 MeloFi에 없는 개념(FL Cloud, Patcherize, ASIO, 멀티링크, CPU 패널 등)이라 측정 제외.
색·질감·아이콘 그림은 요청대로 측정하지 않았고, FL의 그림이나 로고는 쓰지 않았습니다.

1~3차(docs/fl-workflow-comparison.md)는 "FL 강좌대로 곡을 만들 수 있는가"를 98개 항목으로 쟀고 100%였습니다.
이번에는 매뉴얼의 **화면 요소·메뉴 항목·마우스 동작·단축키** 하나하나를 쟀기 때문에 항목이 훨씬 많고 기준이
엄격합니다. 같은 기준으로 이번 작업 **전**과 **후**를 함께 적었습니다.

## 남은 차이 (맞추지 않은 이유)

- **F12 = 모든 창 닫기**: MeloFi에서 F12는 피아노 창에서 Studio를 여닫는 키라 그대로 두고 보기 메뉴에 넣었습니다.
- **숫자 키 1~0 = 채널 음소거**: MeloFi는 PC 키보드로 건반을 치므로 숫자 키를 쓰지 않았습니다.
- **채널마다 자기 믹서 스트립**: MeloFi 믹서는 채널 스트립 + 믹서 트랙(버스) 구조입니다. 바꾸면 기존 프로젝트의 소리가
  달라지므로(오디오 품질 우선) 구조는 두고, 라우팅 상자·트랙 메뉴·번호로 FL 조작을 맞췄습니다.
- 아직 없는 것: 오토메이션 녹음, 디스플레이 필터 그룹, Burn MIDI, Paint drum mode·Interpolate·Play
  selected 도구, Claw machine·LFO, Slip edit, 트랙 그룹, 여러 Arrangement, 믹서 색·도킹·
  라우팅 케이블·레이아웃 보기, 브라우저 탭과 믹서 슬롯으로 끌기, Cut groups·Echo delay, 창 자석·최대화.

테스트: `tools/e2e/fl-parity-e2e.js` (이번에 바뀐 동작 하나하나), `tools/e2e/studio-e2e.js`, `tools/e2e/sweep-e2e.js`.
