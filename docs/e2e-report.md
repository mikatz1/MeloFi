## 1. E2E 테스트

`tools/e2e/studio-e2e.js`는 앱을 화면 없이 실제로 띄워 피아노, Studio, AI 분석, 투어를 끝까지 사용해 보는 스크립트입니다. 항목마다 그 사이에 난 오류(창 오류, 처리되지 않은 Promise, `console.error`)를 모아 판정합니다.

```bash
MELOFI_SHOT=out MELOFI_SCRIPT=tools/e2e/studio-e2e.js MELOFI_USERDATA=out/ud npx electron .
```

## 2. 이번 E2E에서 찾아 고친 버그

| # | 증상 | 원인 | 수정 |
|---|---|---|---|
| E1 | 박자 엔진이 다운비트를 2박마다 잡은 구간이 곡의 절반을 넘으면, 마디 정리가 오히려 반 마디를 기준으로 삼음 | 마디 길이를 다운비트 간격의 중앙값으로 정함 | 더 안정적인 **비트 간격 × 박자 수**로 마디 길이를 정함(비트가 없을 때만 다운비트 사용) |
| E2 | **FM Electric Piano 고음(A#6 이상)에서 엉뚱한 금속성 배음** | 'tine' 변조 주파수(음 높이 ×14)가 24 kHz를 넘어 브라우저가 24 kHz로 잘라 버려 배음 비율이 틀어짐. 로그에 `Oscillator.frequency … clamped` 경고 12건 | 한계를 넘는 음은 tine 소리를 빼고 본체 소리만 냄. 경고 0건 |
| E3 | 투어 '화면 구성' 애니메이션이 가끔 오류로 멈춤 | 첫 프레임의 시각이 시작 시각보다 살짝 앞서 진행값이 음수가 되고, 없는 칸을 읽음 | 시각을 0 아래로 내려가지 않게 막음(모든 애니메이션에 적용), 칸 번호도 범위 안으로 제한 |

## 5. 개선 사항

**AI 곡 분석(외부 오픈소스, 이 PC에서 실행)**
- **분리:** BS-RoFormer ep317(보컬), BS-Roformer-SW(6악기), Mel-Band RoFormer(리드 보컬/코러스), MDX23C DrumSep(킥, 스네어, 탐, 하이햇, 라이드, 크래시).
  - MUSDB18 기준(SDR): 드럼 10.89, 베이스 9.42, 그 밖 7.97, 보컬 12.4 dB.
- **박자·채보:** Beat This(박자·템포), Basic Pitch(채보), MuScriptor small/medium/large(약 35개 악기, 비상업 CC BY-NC 4.0 표기).
- **분석 창:**
  - 시작 전에 방식(분석 엔진, 악기 분리, 채보)을 드롭다운에서 고름.
  - 실시간 로그 창과 진행 막대 2개(현재 단계 / 전체).
  - 분석 전 GPU 확인: 모델별 필요 메모리, 사용률, 피아노 화면을 그리는 GPU. 2초마다 새로 읽음.
  - 단계별 예상 시간 표시.
  - 채보 방식만 바꾸면 분리와 박자 결과는 다시 쓰고 채보만 다시 돌림.
- **분석 결과 → 프로젝트:** 템포 맵, 오디오 트랙(악기별), 8마디 MIDI 패턴.

**Studio**
- FL Studio식 작업 흐름(98개 항목 모두 95% 이상)과 FL 용어.
- Riff Machine 단계별 창, Newtone식 음정 편집, Loop Starter와 루프 라이브러리, 신스 프리셋 28개.
- 분리되는 창, 사이드체인, 녹음 대기(arm), 박자표 마커, 포르타멘토, Ctrl+L, 믹서 트랙 패널.

**투어**
- 13강 78단계, 단계마다 애니메이션(42종), 강의 소개 카드.
- "FL Studio와 같은…" 비교 문구 제거.

**시작 카드**
- 로딩이 끝나면 피아노 / Studio 선택 화면으로 커짐: 상세 정보, 최근 작업, 오른쪽 위 프로필 → 계정 센터.
- 로딩 중 로그인 버튼 제거.

## 6. 남은 일 · 알려진 한계

- **마스터링:** FL Studio·큐베이스 기준 95% 유사도로 나중에 빌드하기로 함.
- **분석의 한계:**
  - 코드 인식이 아직 거침.
  - 짧은 곡(30초 이하)은 BPM을 두 배로 읽을 수 있음.
  - 간이 분석은 구간을 하나만 잡는 경우가 있음.
- **이미 저장한 프로젝트:** U1, U4 이전에 만든 프로젝트에는 잘못 잡힌 마디가 남아 있음. AI 분석 창에서 다시 만들면 됨(분석 결과가 저장돼 있어 바로 만들어짐).
- **E2E로 확인하지 못한 것:**
  - 실제 파일 저장/열기 대화상자, WAV/MP3/영상 내보내기 파일 쓰기, 마이크 녹음, VST, 보컬(NNSVS), 계정 서버, MIDI 장치. 대화상자나 장치가 필요해 자동 실행에서 빠짐.
  - 오디오 파형이 템포 맵을 따라 그려지는지는 직접 화면으로 보지 않았음.
- **GitHub:** origin은 `0af1200`에 머물러 있음. 새 커밋 push는 사용자가 직접 해야 함(현재 토큰에 권한 없음).
