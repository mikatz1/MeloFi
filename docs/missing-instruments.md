# 매칭 90% 미만 파트 · MeloFi에 없을 가능성이 큰 악기

음색 매칭(docs/timbre-matching.md)에서 최고 일치도가 90%에 못 미친 유효 파트(곡에서 꾸준히 연주되는 것; 한두 번만 들리는 잡음성 파트는 뺌)를 매칭을 돌릴 때마다 덧붙입니다. 인터넷에서 실제 무료 악기(샘플 라이브러리)를 찾아 넣을 때 쓰는 목록이에요. 합성으로 만들지 않습니다.
