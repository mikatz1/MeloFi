# FL Studio 작곡 흐름 대조와 유사도 측정

기준 자료 (2026-11-11 확인)
- Image-Line 공식 강좌 **Learn FL Studio** (13강): https://www.image-line.com/learn
- FL Studio 공식 매뉴얼: 단축키(basics_shortcuts), Channel Rack, Piano roll, Playlist, Mixer 페이지

표시와 점수: **●** 같은 방식(같은 창·같은 조작) = 1 · **◐** 기능은 있으나 범위·조작이 다름 = 0.5 · **○** 없음 = 0
색상과 질감(테마 색, 그라데이션, 노브 모양)은 요청대로 측정에서 뺐습니다.

## 남은 차이

측정 항목은 모두 ●입니다. 측정 밖의 차이: 루프 라이브러리 규모(FL Cloud는 수십만 개, MeloFi 루프는 6장르를 키·템포·변형으로 생성), FL 전용 신스(Sytrus·Harmor 등)의 깊이, Newtone의 슬라이스 편집(노트를 자르고 붙이는 기능)과 포먼트 조절.

## 이번에 바뀐 것

3차 (남은 ◐ 두 개와 용어)
- Riff Machine: 단계별 창(Chord progression → Arpeggiate → Groove → Mirror → Levels), Alt+R은 FL처럼 Randomize
- Newtone: 오디오 클립을 노트 블롭으로 보여 주고 끌어서 음정·길이 수정, Center·Variation, TD-PSOLA 렌더(실제 보컬에서 옮긴 노트 오차 중앙값 2.8센트, 손대지 않은 부분은 원본과 비트 단위로 같음)
- 화면 용어를 FL Studio 이름으로 (위 표), 튜토리얼·힌트 바 반영

2차 (모든 영역 95% 이상으로)
- 떠 있는 창: 피아노 롤·플레이리스트·믹서 떼어내기/붙이기, ‘창’ 메뉴, FL 기본 배치, 배치 저장
- 채널 설정 창을 FL 플러그인 창처럼 떠 있게
- MeloFi 신스 프리셋 28종을 악기 선택 창에서 분류별로
- MeloFi 루프 라이브러리와 오디오 루프 스타터(셔플)
- 튜토리얼 78단계로 갱신, 스튜디오 툴바의 ‘피아노’ 버튼 제거
- 고친 버그: 오프라인 렌더(WAV·MP3·스템)가 샘플이 전달되기 전에 시작돼 일부·전체가 무음이 되던 문제, 어택보다 짧은 신스 노트가 무음이던 문제, ‘화면 꾸미기’ 설정이 재시작 후 사라지던 문제, 툴바에 ‘null’ 글자가 뜨던 문제

1차

- 단축키 배열을 FL과 같게 (F4–F9, L, Alt+F8, Ctrl+R 계열, 도구 키, Ctrl+Shift 조합 버그 수정, Space가 어디서나 재생되도록 수정, Alt+Q 동작 안 하던 버그 수정)
- 피아노 롤·플레이리스트 도구 모드(그리기·페인트·지우기·뮤트·자르기·선택·확대·슬라이드·포르타멘토), 플레이리스트 다중 선택
- 고스트 노트는 원래 있었음(이전 판의 ‘없음’은 잘못)
- 믹서: 여러 센드, 오디오 기준 사이드체인, 인서트 패널, 녹음 대기·입력 선택, Ctrl+L
- 피치 보정 이펙트, 리프 머신(Alt+R), 루프 스타터, 박자표 마커(Shift+Alt+T), F2·Alt+C
- 브라우저 왼쪽 도킹, 툴바 패턴 선택, 화면 꾸미기, 화면 건반 별도 창
- 튜토리얼을 Learn FL Studio 13강 순서로 다시 작성 (75단계, 문구는 Gemini Flash로 다듬고 뜻은 직접 확인)
